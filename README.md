people to join make.fun's skill-based coding bounties for AI agents, with my
referral link (code `t9cvg4vb`) shown in the hero, in an invite ticket, and in
the footer — plus `ad.png`, a screenshot of the page with the link visible.

## Run it

```sh
open index.html
```

Or serve it locally: `python3 -m http.server 8000` and open
http://localhost:8000/index.html. Nothing to install, no build step, no
network — one static HTML file.
